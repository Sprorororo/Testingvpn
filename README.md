# SavaVPN (beta)

Android-клиент на базе открытого ядра sing-box. Построен путём
репакинга официальной сборки **sing-box for Android (SFA)** с
собственным брендингом, экраном приглашения и зашитой подпиской.

## Что делает CI-сборка

1. Скачивает официальный подписанный APK SFA с F-Droid (версия 1.13.21)
2. Распаковывает через `apktool`
3. Патчит:
   - название приложения → **SavaVPN (beta)**
   - иконку → генерируется программно (зелёный щит)
   - акцентные цвета темы
   - добавляет собственный экран приветствия с кнопкой «Подключить»,
     которая через официальный deep-link `sing-box://import-remote-profile`
     добавляет твою подписку `Sava2.txt`
4. Собирает APK обратно, подписывает собственным ключом
5. Публикует `.apk` как артефакт сборки (и как GitHub Release при
   ручном запуске)

## Как запустить

1. Создай новый **публичный** репозиторий на GitHub (публичный — это
   требование лицензии GPL-3.0 исходного проекта, под которой
   распространяется ядро sing-box).
2. Залей туда всё содержимое этой папки как есть, сохранив структуру.
3. В репозитории: вкладка **Actions** → workflow **"Build SavaVPN APK"**
   → **Run workflow** (кнопка справа) → **Run workflow** ещё раз для
   подтверждения.
4. Подожди 3–5 минут, пока сборка выполнится.
5. Если сборка **позеленела** (успех) — зайди в неё, внизу будет
   раздел **Artifacts**, там `.apk` файл — скачивай и ставь на телефон
   (разреши установку из неизвестных источников).
6. Если сборка **покраснела** (ошибка) — открой упавший шаг, скопируй
   текст ошибки (весь красный вывод) и пришли мне — я поправлю
   соответствующий скрипт.

## Известные риски первой версии

Самый technically рискованный шаг — `patch/patch_subscription.sh`: он
добавляет собственный экран приветствия напрямую через низкоуровневый
байт-код (smali), потому что мы не пересобираем исходники, а патчим
уже готовый бинарник. Это самое вероятное место, где что-то может
пойти не так — либо сборка не пройдёт, либо экран покажется, но кнопка
не сработает как надо. Если так случится — это ожидаемо, присылай лог
ошибки или опиши поведение, поправим прицельно.

Если хочешь на всякий случай подстраховаться — можно временно закомментировать
вызов `patch_subscription.sh` в `patch/apply_patches.sh` (поставить `#`
перед строкой), тогда соберётся приложение с оригинальным экраном SFA
без нашего экрана приветствия — уже полностью рабочий VPN-клиент, куда
подписку можно добавить вручную один раз через встроенное меню
«Add Profile» → «Remote» → вставить ссылку
`https://gitverse.ru/api/repos/S_pro/Sava/raw/branch/main/Sava2.txt`
и включить автообновление раз в 24 часа в настройках профиля.

## Лицензия и происхождение кода

Ядро приложения (sing-box / libbox) распространяется по лицензии
**GPL-3.0**. Это приложение — производная работа, что требует
сохранения открытости исходного кода. В описании приложения в сторах
или на странице проекта следует указать, что SavaVPN построен с
использованием наработок открытых VPN-клиентов на базе sing-box
(включая проекты семейства sing-box-for-android и им подобные).

## Структура проекта

```
.github/workflows/build.yml   — основной CI-пайплайн
patch/apply_patches.sh        — точка входа, вызывает все патчи по порядку
patch/patch_strings.sh        — смена названия приложения
patch/patch_icon.sh           — генерация и подстановка иконки
patch/patch_colors.sh         — смена акцентных цветов
patch/patch_subscription.sh   — экран приветствия + зашитая подписка
```
